# SQL-Based AI Assistant

An AI-powered assistant that converts natural language questions into SQL queries, validates and executes the queries on a PostgreSQL database, and returns the results in a user-friendly format.

## Overview

The SQL-Based AI Assistant allows users to interact with structured database data using natural language instead of writing SQL queries manually.

The system uses an LLM to understand the user's question, generate SQL based on the database schema, validate the generated query, execute it on PostgreSQL, and handle SQL errors through an automatic correction step.

### Example

**User question:**

> What is the total revenue?

**Generated SQL:**

```sql
SELECT SUM(price) AS total_revenue
FROM order_items;
```

**Result:**

```text
Total Revenue: 13,591,643.70
```

## How It Works

### 1. Natural Language Input

The user enters a business question in natural language.

Example:

```text
Which category generated the highest revenue?
```

### 2. SQL Generation

The LLM receives the user's question along with relevant database schema information and generates an SQL query.

### 3. SQL Validation

The generated query is validated before execution.

The validation layer checks for:

* Empty queries
* Multiple SQL statements
* Invalid query structure
* Non-SELECT operations

Only read-only `SELECT` queries are allowed to proceed.

### 4. Query Execution

The validated SQL query is executed against the PostgreSQL database.

### 5. Error Correction

If the generated query produces a database error, the system uses the original question, generated SQL, schema information, and database error to generate a corrected query.

### 6. Result

The final database result is returned in a user-friendly format.

---

## SQL Safety

Since SQL is generated by an LLM, directly executing generated queries can be risky.

This project includes a validation layer that restricts execution to read-only queries.

For example, destructive queries such as:

```sql
DROP TABLE customers;
```

are rejected instead of being executed.

This provides an additional safety layer between the LLM and the database.

## Installation

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd SQL-Based-AI-Assistant
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the environment

**Windows:**

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure environment variables

Create a `.env` file:

```env
DB_HOST=localhost
DB_PORT=5433
DB_NAME=your_database
DB_USER=your_username
DB_PASSWORD=your_password

GROQ_API_KEY=your_api_key
```

Keep `.env` private and do not commit API keys or database credentials to GitHub.

### 6. Run the application

If the project uses Streamlit:

```bash
streamlit run app.py
```
